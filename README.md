## Edit Markdown in Your Browser

Write Markdown on the left and watch the **live preview** update on the right. Your draft is saved automatically in this browser.

## What you can try

- Import a local `.md`, `.markdown`, or `.txt` file.
- Use GitHub-flavored Markdown tables and task lists.
- Download your work as Markdown, HTML, PDF, or DOCX.
